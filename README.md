# 中华文明 ChinaCiv — 25km 六边形战略地图

将真实公开中国数据投影至 **China Albers 等面积 25 公里正六边形网格** 的《文明》风格交互式战略地图（参考 [usaciv](https://karpathy.ai/usaciv/)）。

- **在线访问**：https://dreamlovebetty.github.io/chinaciv/
- **空间网格**：`211 × 275`（`17,598` 块中国陆域 25km 六边形），完整覆盖 `34` 个省级行政区与 `1,302` 个县域单元，融合 Aliyun DataV 边界、GADM 县界、AWS Terrarium DEM 高程与 Natural Earth 河湖水系。
- **19 种数据视角**：人口密度、可支配收入、住宅均价、低收入占比、中位年龄、外来流入人口、高学历比、宽带普及率、通勤时间、住房自有率、医疗保障缺口、森林/耕地/建设用地占比、宗教民俗活跃度与主要传统信仰、健康福祉指数、自然灾害频次（含 USGS 地震实录）、STEM 科研人才占比。
- **34 省城市视图与 107 座城市**：真实产业城区徽牌（北京双学院区、上海金融中心等）与市民构成对比（深圳每 5 名劳动者中 1 名工程师/程序员/科学家 vs 全国平均每 14 人 1 名）。
- **9 位顾问与 1,302 县域探索者**：涵盖能源、经济、人口（胡焕庸线对比）、民生、科教、国土、军事、商贸、文化奇观，以及支持任意列定制、散点相关性计算、矩形框选并与地图双向联动的探索者工具。

## 本地运行

```bash
python3 -m http.server 8765 -d web
```

随后在浏览器打开 `http://127.0.0.1:8765/`。
